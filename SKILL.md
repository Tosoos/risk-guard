# Risk Guard

AI-навык для анализа криптопортфеля.

Функции:
- Анализ распределения активов
- Оценка риска концентрации
- Анализ диверсификации
- Рекомендации по ребалансировке
- Генерация отчётов

Вход:
- Адрес кошелька NEAR

Выход:
- Risk Score
- Portfolio Summary
- Recommendations
- Rebalancing Plan
